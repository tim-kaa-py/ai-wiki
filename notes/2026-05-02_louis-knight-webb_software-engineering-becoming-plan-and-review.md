# Ingest Notes

**Source:** [Software Engineering Is Becoming Plan and Review — Louis Knight-Webb, Vibe Kanban](https://m.youtube.com/watch?v=W76woOYHlvY)

## User Focus

- Plan/review thesis: AI displaces coding time into planning + reviewing; "5 min planning saves 30 min reviewing"
- Two work modes: plan-heavy (spec up front, low review cost) vs review-heavy / in-the-loop (YOLO + correct iteratively)
- Work-type matrix: when to plan vs when to be in-the-loop, mapped across front-end/back-end × feature/migration
- Agent time-horizon shift: seconds → minutes → tens of minutes per run; each added tool tier (typecheck → Playwright MCP) trades latency for accuracy
- Front-end QA via Playwright/Chrome MCP as the predicted next breakthrough
- Parallelism / "terminal maxing": running multiple agents concurrently to bridge wait times; developer becomes a manager of streams
- "Focus maxing" anti-pattern warning: don't pull humans in/out of contexts every 30s — design for long agent runs that yield back to humans
- Four jobs of the new coding-agent IDE: write/plan tasks, QA, code review, shepherd change to deploy
