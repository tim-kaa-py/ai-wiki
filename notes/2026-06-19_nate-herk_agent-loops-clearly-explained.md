## User Focus
- What is a loop?
- Which elements constitute an effective loop?
- When does it make sense to create a loop?

## Confirmed Discoveries
- **B [03:04-04:03]** — Quality-vs-attempts mental model: AI never one-shots; plot quality (y) against attempts (x). The loop outsources the human feedback-iteration cycle to the agent so you climb the curve faster. The clearest argument for *why* loops work at all.
- **C [05:45-06:11]** — Four loop topologies named: solo loop (one agent, his most-used), maker-checker (one does, one grades), and manager-with-helpers/orchestrator. Architectural taxonomy that adds a dimension beyond the core elements.
