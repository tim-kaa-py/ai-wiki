# Ingest Notes

**Source:** [Claude Mods Is The Biggest Claude Code Upgrade Since Skills](https://www.youtube.com/watch?v=Rn4nmFRPe0s)

## User Focus

- **When to invoke:** mods are never invoked; once installed they run automatically like a hook until removed, unlike a skill. They live in the plugin system (`/plugins`) and can be switched off by asking Claude (04:14–04:22, 08:15–08:38).
- **What can I do:** rewrite events, change the UI, edit or add whole features — "the plumbing of this harness" (00:14–00:28, 01:06–01:33, 03:23–03:31).
- **Modify UI:** next-steps pane with three clickable follow-up prompts; cache clock with cold-cache countdown and compact button; same in Desktop app and terminal (04:27–07:04).
- **Intercept on events:** before / replace / after / wrap, shown as four mods on one "delete this folder" action — preview, recycle bin, receipt, backup-for-undo (01:37–03:23).
- Exclude the sponsor segment (03:40–04:06).

## Confirmed Discoveries

- **A. Self-audit prompt to design your own mods (07:04–08:15):** "Audit how I use Claude Code, read my last 30 sessions, see what I ask for over and over, suggest five mods" — then Claude builds and installs the chosen one.
